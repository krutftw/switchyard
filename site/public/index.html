PowerShell examples, with the CLI on your PATH.

Switchya CLI
# An interactive session
PS> switchya chat `
    --project C:\projects\my-project `
    --model MODEL

# A focused task
PS> switchya run `
    --project C:\projects\my-project `
    --model MODEL `
    --prompt "Explain the test failure"

Use an existing folder and a model ID from switchya models. For terminal-only use, close the desktop first.

Switchyard Gateway.

A standalone API gateway for your existing tools. Run it on your machine or server, add your provider credentials, and connect compatible clients to one endpoint.

Download the Gateway

Gateway v0.1.0 for Windows and Linux x64.
The Gateway is separate from the Switchya app.

API compatibility
OpenAI Chat Completions, Responses, Anthropic Messages, and Gemini protocols, with streaming.
Routing and operations
Model aliases, credential pools, cooldowns, and failover, with a built-in dashboard.
Runs on your infrastructure
A single Rust binary. Upstream access uses your API keys or service accounts.
